# data-agent-audit-replay-ui - 使用与精进指南

## 这个 Skill 解决什么
把“问数能力”和“审计回放能力”可视化，服务分析师/管理员/审计员。

## 推荐使用顺序
1. 先实现 `/query` + `/replay` 两个 API。
2. 再做 UI 三层：问数区、回放区、详情区。
3. 最后加角色规则（admin 明文、非 admin 脱敏）。

## 精进路线（下一阶段）
- P1：加入回放列表虚拟滚动与大数据量分页优化。
- P2：加入筛选收藏与分享链接（参数序列化）。
- P3：加入可视化解释卡（口径版本、时间窗、权限命中）。
- P4：接入 SSO 角色映射，替代手工选择角色。

## 验收建议
- UI 改动必须带“元素存在性”测试。
- 回放改动必须带“掩码规则 + 错误码矩阵”测试。
