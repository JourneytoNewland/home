# data-agent-prod-hardening - 使用与精进指南

## 这个 Skill 解决什么
为上线前阶段提供统一的加固动作：稳定性、安全、可观测、发布与回滚。

## 推荐使用顺序
1. 先做只读安全与权限扫描。
2. 再做可观测（trace/指标/日志）补齐。
3. 然后做压测与容量评估。
4. 最后做灰度和回滚演练。

## 精进路线（下一阶段）
- P1：建立自动化发布闸门（未达阈值禁止上线）。
- P2：建立按业务域分层告警（噪声抑制 + 升级策略）。
- P3：建立审计归档和保留策略（冷热分层）。
- P4：建立故障演练脚本库（注入失败/超时/数据漂移）。

## 验收建议
- 上线前必须完成一次全链路回滚演练。
- 必须有 P95/P99 与错误码分布的基线报告。
