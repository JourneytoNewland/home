# Skill: data-agent-prod-hardening

## 用途
用于将 Data Agent 从“可演示”推进到“可上线”的标准化加固流程。

## 适用场景
- 已有 NL2LF2SQL 主链路和基础测试
- 需要上线前做压测、灰度、告警、回滚方案

## 标准步骤
1. **可靠性加固**
   - 增加超时、重试、熔断策略
   - 执行层只读白名单（禁 DDL/DML）
2. **可观测性完善**
   - 全链路 trace_id/request_id/user_id
   - 指标：成功率、P95时延、拒绝率、回放命中率
3. **安全与权限**
   - 默认拒绝策略复核
   - 脱敏规则回归
4. **数据口径治理**
   - 指标版本变更审批流
   - 生效窗回滚演练
5. **性能压测**
   - 100表规模 LF 生成与执行压测
   - Replay 查询分页压测
6. **发布策略**
   - 灰度（角色/租户/业务域）
   - 回滚开关（配置优先）

## 验收清单
- [ ] 同输入一致性回归通过
- [ ] 权限越权扫描通过
- [ ] 审计回放契约稳定
- [ ] 压测达标（P95/P99）
- [ ] 灰度与回滚演练完成
