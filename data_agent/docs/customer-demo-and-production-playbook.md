# Data Agent 客户演示与生产落地手册

> 目的：将“可运行骨架”转化为“可对外演示 + 可对内落地”的标准作业文档。

## 1. 代码位置与运行入口
- 项目根目录：`/workspace/home`
- 核心实现：`data_agent/src/`
- UI 页面：`data_agent/ui/index.html`
- UI 服务：`python3 -m data_agent.ui.server`
- Demo 脚本：`python3 data_agent/scripts/demo_run.py`

## 2. 客户演示脚本（5分钟）

### 2.1 开场（0:00 - 0:40）
- 一句话：Data Agent 是“可治理、可追踪、可复盘”的企业问数系统，而非黑箱聊天。
- 强调三点：确定性、权限治理、审计回放。

### 2.2 实机演示一：智能问数（0:40 - 2:00）
1. 启动 UI 服务并打开 `http://127.0.0.1:8010`。
2. 在“智能问数”输入业务问题并执行。
3. 展示 `trace_id`、metric、role、time_range、SQL 复制按钮。

### 2.3 实机演示二：审计回放（2:00 - 3:30）
1. 切换到“审计回放”。
2. 使用角色/排序/分页/trace_id 过滤组合回放。
3. 展示分页边界行为（首页禁用上一页、末页禁用下一页）。

### 2.4 机制讲解（3:30 - 4:30）
- 语义层：配置驱动指标口径和版本。
- 权限层：默认拒绝，按角色控制。
- 执行层：只读执行模式，降低风险。
- 审计层：全链路追踪与回放。

### 2.5 收尾（4:30 - 5:00）
- 当前版本是可运行骨架；可按下文生产清单逐项升级到企业上线。

## 3. 生产落地清单（从 Demo 到上线）

### 3.1 P0（上线门槛）
- 接入企业统一身份鉴权（SSO/OAuth2）。
- 角色/字段/行级权限策略中心化。
- 审计存储外部化（DB/对象存储）。
- API 入参与错误码统一治理。
- 日志/指标/链路追踪可观测性。

### 3.2 P1（稳定性）
- 数据源连接池、SQL 超时、熔断与重试。
- 语义配置发布审批、灰度、回滚机制。
- 固定问句回归集与质量基线。
- 敏感数据脱敏与合规保留策略。

### 3.3 P2（精品化与长期竞争力）
- 多 Agent 协作与任务编排。
- RAG 术语知识库与自动澄清。
- 可视化 lineage 与团队协作工作台。
- A/B 实验、反馈闭环与策略版本化。
